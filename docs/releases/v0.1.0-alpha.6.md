A security release for the fifth alpha. A security audit found ways for a repository's own content to run commands on a host or read files it shouldn't; this alpha closes them. It also fixes GitHub sign-in behind a corporate proxy.

## Fixed in this alpha

- **GitHub sign-in works behind a proxy.** The app now uses your system's proxy settings and trusted certificates, so sign-in, pull requests and update checks work behind tools like Zscaler. When GitHub can't be reached, adding an account says why and offers Try again, instead of doing nothing.
- **Approve on a notification answers once.** On Windows, approving from a notification could also show "Couldn't answer … is already resolved".
- **A repository can't run commands through Polaris's own git.** The git Polaris runs by itself (status, diffs, checkpoints, review checkouts, search) no longer runs a repository's hooks, filters, fsmonitor, diff drivers, pager, ssh command or credential helpers, never enters submodules, and never quietly downloads missing objects in a partial clone. Git you run from changes, sync and accept keeps your own config and hooks.
- **Worktrees Polaris makes don't run Git hooks.** That covers new sessions, forks and restores.
- **Worktree setup runs only in workspaces you trust on that host.** A worker whose setup would install dependencies is refused until you trust the workspace (from the editor). Setup gets a minimal environment, without tokens or your SSH agent.
- **Review Run and the reviewer stay contained.** Commands from a pull request in Review Run get a minimal environment with no provider keys or tokens. The reviewer reads only its checkout, with no network, through Claude Code's or Codex's own sandbox.
- **Opening files is bounded.** Links from agents open files only inside a workspace, the editor refuses files over 64 MB, and image previews and diagrams are measured before they're decoded, so a crafted image can't exhaust memory.
- **Installing a daemon on a host is safer.** The download is size-checked as it streams, and installs stage in a private folder.

## Changed

- **The reviewer can't run toolchains installed in your home folder** (like `~/.bun` or `~/.nvm`), so it won't run tests or lint for those projects. The reviewer needs Claude Code, Codex 0.159.2 or later, or OpenCode.
- **Diagrams in the conversation and in hovers that load images or set `%%{init}%%` config** show as failed diagrams.
- **In a blobless or treeless clone**, Polaris's own diffs of objects you haven't downloaded show as unavailable until your git fetches them. Review still works: it downloads what the checkout needs.

## Installing

These builds aren't signed yet, so macOS and Windows will warn you the first time.

**Mac (Apple silicon).** Download `Polaris-0.1.0-alpha.6-arm64.dmg` and drag Polaris to Applications, then open it. macOS will refuse the first time. Open System Settings → Privacy & Security, scroll to the message about Polaris, click **Open Anyway** and confirm. On macOS 14 and earlier, right-click Polaris in Applications and choose **Open** instead.

**Windows.** Download `Polaris-0.1.0-alpha.6-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

You'll also need at least one agent, like Claude Code or Codex, installed wherever you want agents to run.

## Known limitations

- **No automatic updates between alphas.** Prereleases aren't on polaris.lux.dev or its update feed, so install the next alpha from this page by hand. The unsigned Mac app can't update itself at all, so checking for updates on a Mac says "Couldn't check for updates".
- **Unsigned.** Gatekeeper and SmartScreen warnings are expected until signing is set up.
- **Mac app is Apple silicon only.** Linux machines (x64 and arm64) work as hosts, not as a desktop app.
- **Windows is experimental.** No local host, and CI only smoke-tests the x64 installer.
- **A host's own downloads don't use a corporate proxy's certificate yet.** Language servers and the edit prediction model download on the host, which doesn't yet trust a certificate a tool like Zscaler installs.
- **Edit predictions are tuned for TypeScript.** Other languages get suggestions without the language-server check.
- **A Raspberry Pi 4 doesn't serve completion.** Point it at a model server on a larger machine.
