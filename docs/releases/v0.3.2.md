A fix for the Raycast extension: it loads.

## What's new

### Extensions (experimental)

- **Raycast opens.** 0.3.1's extension installed but failed to open with "Package subpath './Cause' is not defined by exports". Download `polaris-raycast-0.3.2.zip`, unzip it, and in its folder run `npm install` then `npm run dev`. `npm run build` now builds into the folder's `dist/` instead of over the copy Raycast has installed.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.3.2-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.3.1 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.3.2 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.3.2-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** The daemon is unchanged apart from its version. With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.3.2 the next time it connects.

## Known limitations

0.3.0's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.3.0) still apply.
