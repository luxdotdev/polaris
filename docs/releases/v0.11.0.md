The transcript now shows what an agent changed, right where it changed it: each edit carries its first changed lines, highlighted, and a shell command that rewrites files shows them too. Markdown renders on a new engine with math and diagrams built in, and code everywhere is highlighted in the Editor's colours. Polaris also downloads its own updates with progress, skips straight to the newest release, and offers a **Nightly** channel.

## What's new

### Edits in the transcript

- **Inline edits.** A file an agent edits shows `+N −M` and its first 8 changed lines, highlighted. **Show all N lines** opens every hunk in place. While the agent is still writing, the row reads **Writing index.html**. Click the path to open the file in the changes panel.
- **Script edits.** Agents often edit with a script (`sed -i`, a `python3` heredoc, a redirect) rather than an edit tool. A shell command that isn't plainly read-only now shows **Changed N files** under it, with the same preview. Your host snapshots the working tree around the command with its own index; your index, branches and files are never touched.
- **Large changes stay light.** A file's patch is capped, and so is each turn's; past a cap a row shows its counts only. On a tree too large to snapshot quickly, a command shows file names only.

### Markdown and code

- **A new Markdown engine.** Replies, documents and Review render through Words. Math works with `$…$`, `$$…$$`, `\(…\)` and `\[…\]`, and a lone `$` stays a dollar. Mermaid diagrams render in place. Footnotes link both ways.
- **Code in the Editor's colours.** Code blocks, Review diffs, the Editor's Markdown preview and LSP docs all highlight with the Editor's theme, in Moonlit and Light. A code block that is still streaming highlights each line as it completes, without flicker.

### The changes panel and Output

- **The whole session.** The changes panel shows everything the agent session changed by default; the turn menu narrows it to one turn. Output opens itself at most once per agent session, on the first edit, and never closes itself.
- **A compact Output rail.** Closed, the Output rail is a status view: what's happening now, the session's changed files with their counts, where it runs (host, workspace, branch, PR), and the browser or simulator in use.
- Closing the terminal drawer's last tab closes only the drawer.

### Updates

- **Download progress.** Polaris downloads its own updates, resumably, and shows the amount and a bar in Settings → About. It verifies each download before installing it: its code signature on a Mac, its size and checksum on Windows.
- **Straight to the newest.** If a newer release comes out while one is ready, Polaris downloads the newer one and installs that instead.
- **Nightly.** Settings → About has a **Channel**: Stable or Nightly. Nightly is a prerelease built from main each night, and may break. Going back to Stable never downgrades: a nightly stays until a Stable release is newer.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.11.0-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.10.0 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.11.0 is ready. Download progress and the Channel start with 0.11.0.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.11.0-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.11.0 the next time it connects. Inline edits and script edits need the host on 0.11.0; an older host keeps today's file rows.

## Known limitations

- **Inline and script edits** come from Claude Code agent sessions only.
- **Updates on Windows** go through the new downloader but haven't been tested against a real Windows install yet (ENG-985).
- Switching to Stable doesn't cancel a nightly that is already staged; it installs when you quit (ENG-993).
- 0.10.0's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.10.0) still apply.
