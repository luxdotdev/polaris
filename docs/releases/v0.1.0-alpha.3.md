The third Polaris alpha: a much smaller download, and fixes from the first round of testing. It's for testing: expect rough edges, and tell us what breaks.

## New in this alpha

- **A smaller download.** The Mac app is about 174 MB instead of 390 MB. It now carries only its own daemon; a remote host downloads the build it needs from polaris.lux.dev (checked against the checksum this app shipped with), and the app uploads it over SSH when the host can't.
- **The app installs this Mac's daemon.** On first launch the app installs and starts the daemon it carries. If the daemon won't start, the host row shows why, from its own log.
- **The reviewer runs on hosts without Claude Code's sandbox.** Where Linux lacks bubblewrap or socat, the reviewer reads files without a shell and the risk summary says what to install, instead of failing.
- **Sessions that can't start say so.** An agent that doesn't start within 90 seconds, or crashes starting, fails the session with the reason.
- **Request reviewers and merge from Review.** A Reviewers popover, and Merge with the repository's methods, branch deletion and checkout cleanup.
- **Windows fixes.** Language identity works on Windows, no stray console windows, and copy that no longer says "Mac" on a PC.

## Also in it

- **The editor, with language tooling v2.** Language servers for TypeScript, Python, Go, Rust, Java, PHP, Lua, SQL, Svelte and more, on any host. Rust and Lua servers download on demand and stay locked down until you trust the project.
- **Tab completion v1.** Suggestions as you type, from a model server you run: llama-server, LM Studio, Ollama or any OpenAI-compatible endpoint. Nothing leaves your machines.
- **The completion status card.** Hover the completion item in the status bar to see where completion runs, how fast it answers and how much context it sent, switch models, or recover a stuck server.
- **Diff tabs.** Click a file in Changes to open its diff in an editor tab, unified or split. Syntax-aware diffing matches lines by token, so only what changed is highlighted.
- **A Reviewed group in the review queue.** A pull request you've reviewed moves to the bottom and the next one opens. New commits bring it back.
- **Hidden workspaces.** Right-click a workspace in the top bar to hide it. Nothing is deleted, and a hidden workspace still shows up while one of its sessions needs you.
- **Windows, experimental.** An x64 and an arm64 installer. The Windows app connects only to remote hosts.

## Installing

These builds aren't signed yet, so macOS and Windows will warn you the first time.

**Mac (Apple silicon).** Download `Polaris-0.1.0-alpha.3-arm64.dmg` and drag Polaris to Applications, then open it. macOS will refuse the first time. Open System Settings → Privacy & Security, scroll to the message about Polaris, click **Open Anyway** and confirm. On macOS 14 and earlier, right-click Polaris in Applications and choose **Open** instead.

**Windows.** Download `Polaris-0.1.0-alpha.3-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

You'll also need at least one agent, like Claude Code or Codex, installed wherever you want agents to run.

## Known limitations

- **No automatic updates between alphas.** Prereleases aren't on polaris.lux.dev or its update feed, so install the next alpha from this page by hand. The unsigned Mac app can't update itself at all, so checking for updates on a Mac says "Couldn't check for updates".
- **Unsigned.** Gatekeeper and SmartScreen warnings are expected until signing is set up.
- **Mac app is Apple silicon only.** Linux machines (x64 and arm64) work as hosts, not as a desktop app.
- **Windows is experimental.** No local host, and CI only smoke-tests the x64 installer.
