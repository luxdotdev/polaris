Extensions arrive, as an experiment: Raycast, Even Realities G2 glasses and your own programs can watch your agent sessions, approve, reply and start new ones, on this Mac or from anywhere on your tailnet.

## What's new

### Extensions (experimental)

- **Pair an extension.** Settings → Extensions pairs an outside program with a host and says what it may do: read, approve, send turns, start agent sessions, voice. Polaris shows a pairing string and a QR code once; the list shows each pairing's last use, and **Revoke** cuts it off at once. On a headless host, `polaris extension pair --name <name> --allow read,approve` does the same.
- **Remote access over Tailscale.** Turn on **Remote access** for a host (Settings → Hosts, or `polaris tailscale on`) and paired extensions reach it at its `ts.net` name, from your tailnet only. Polaris refuses when Tailscale Funnel is on or port 443 is already served, and says what's missing when Tailscale isn't ready.
- **Raycast.** Search agent sessions and workspaces, see pending approvals, approve or deny, send a turn, interrupt, and start an agent session on any paired host. It isn't in the Raycast Store yet: load it from `extensions/raycast` (see its README).
- **Even Realities G2.** See which sessions need you on your glasses, read the last turn or approval, and approve, deny, interrupt or reply, by voice too. It's a private beta for now.
- **Voice.** With a Deepgram key in Settings → Voice, the host transcribes what an extension records. A transcript only becomes a turn when you send it.
- **The SDK.** [`@doellsoftware/polaris-sdk`](https://www.npmjs.com/package/@doellsoftware/polaris-sdk) on npm: pairing strings, several hosts at once, sessions, approvals and turns, from Node or a browser.
- **`polaris://` links.** A link to a session or workspace opens it in Polaris. Links only navigate; they never act.

### Conversations

- **Shell commands in Claude Code sessions.** Type `!` at the start of the composer to run a command in the session's directory; the agent sees its output and replies. On Windows it runs in Git Bash, like Claude Code's own.
- **Run in background.** A running Claude Code command offers **Run in background**, and Ctrl-B moves every command the turn is waiting on.
- **Turns fold alike.** Every turn, the latest included, starts with its tool runs folded.
- **Images in replies.** An image an agent links by path loads from the session's host.
- **Highlighted JSON.** JSON in tool calls is syntax-highlighted.
- **Questions with several parts.** An agent's question with several parts shows every part and sends every answer.
- **Agents read their own history.** Through Polaris's MCP tools an agent can search past sessions in its workspace and read back what compaction dropped from its own.

### Sessions and workspaces

- **Dormant sessions archive themselves.** A session without activity for 7 days is archived; pinned sessions, reviews and open constellations stay, and branches are kept. Change it per host in Settings → Sessions → Archive.
- **Open folder makes a new one.** Open folder can create a folder, which becomes a git repository with a first commit.

### Review

- **The reviewer's answer survives quoted code.** A follow-up whose answer quoted a code block showed raw text and lost its findings; it now reads as Markdown, and its asks scroll instead of covering the file list.
- **Review's header stays in the window.** A long title no longer pushes **Submit review** off the right edge.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.3.0-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.2.2 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.3.0 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.3.0-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.3.0 the next time it connects. Extensions, remote access and shell commands need a host on 0.3.0.

## Known limitations

- **Extensions are experimental.** They have been checked on one Mac and one pair of glasses; expect rough edges, and revoke a pairing you no longer use.
- **Remote access needs Tailscale** with HTTPS certificates on, and on Linux `tailscale set --operator=$USER`. There is no other way in from outside the host, and it hasn't been checked on Windows hosts yet.
- **Raycast isn't in the Store,** and the G2 app is a private beta.
- **Voice uses Deepgram only,** with your own key.
- 0.2.1's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.2.1) still apply.
