GitHub accounts stay signed in on a slow network, a turn reads as one turn from your message to the next, and notifications tell you what the agent said.

## What's new

### Conversations

- **One turn per message.** When an agent carries on by itself, say when a background command finishes, the conversation keeps it inside the turn you started instead of opening a new one. A quiet line says what woke it ("A command finished · 14:25"). Turn numbers, the turn rail, find, **Copy turn output** and the sidebar all count your messages.
- **Syntax highlighting in Changes.** A turn's changes in the session's **Changes** tab are coloured like the editor, in both themes.

### Notifications

- **Only for long turns.** Under **Notify when a turn ends** (Settings → Sessions), you can now choose to be notified only for turns longer than a few minutes (5 by default). A turn counts from your message until the agent has finished, background tasks included, and notifies once.
- **The agent's reply.** A turn's notification shows the start of the agent's last reply, not your own message.
- **Reviews and walkthroughs say they're ready.** A reviewer run notifies as "Review ready" with its findings ("3 findings · 1 critical"), and a walkthrough as "Walkthrough ready". Clicking either opens the review, not the session.

### Fixes

- **GitHub stays signed in.** Opening Polaris on a network that isn't online yet, like one behind a sign-in page, no longer signs out your GitHub accounts. Polaris tries again when GitHub is reachable, and an account signed out this way before signs back in by itself.
- **Markdown preview.** **Load external images** shows only when a document has external images, and the preview keeps a readable line length.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.2.1-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.2.0 or 0.1.0,** Polaris updates itself. Choose **Restart to update** when it says 0.2.1 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.2.1-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts, on by default), Polaris upgrades each host's daemon the next time it connects. Until a host runs 0.2.1, its notifications read "Ready for the next turn" instead of the reply, turn numbers in a long session can shift as older turns load, and a turn the agent continued shows its changes only after the upgrade.

## Known limitations

0.2.0's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.2.0) still apply, plus:

- **The review queue and pull list still number turns the old way,** counting each turn the agent continued by itself.
- **A turn notification waits a few seconds** after the agent finishes, so an agent that carries straight on doesn't notify twice.
