A security update: Polaris no longer trusts certificates issued through eMudhra's compromised intermediate keys.

## What's new

### Security

- **Forged certificates are refused.** In October 2026 the private keys of eight eMudhra intermediate certificate authorities turned out to be guessable, so anyone could issue a certificate for any website that many programs would accept ([details](https://scotthelme.co.uk/eight-bits-of-trust-emudhras-ca-keys-cracked-in-milliseconds/)). Polaris now refuses any connection whose certificate goes through one of those keys, for GitHub sign-in and API calls, daemon downloads and external images in the Markdown preview, whatever your system trusts.
- **Electron 44.9.3.** The latest Electron 44 release, with its Chromium and Node security fixes.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.2.2-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.2.1 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.2.2 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.2.2-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or 0.2.1,** Polaris updates itself.

**Your hosts.** The daemon is unchanged apart from its version. With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.2.2 the next time it connects.

**Your agents.** Claude Code, Codex and the other agents make their own connections. Update them as their own fixes ship.
