A fix release for the fourth alpha: a Mac host's daemon could freeze for good. If you run alpha.4 on a Mac, update.

## Fixed in this alpha

- **The daemon no longer freezes on a Mac.** A terminal whose command printed and exited within moments of starting (a login shell whose startup files failed, or a short command) could deadlock the daemon on a busy Mac. Every agent session, terminal and connection then stopped responding, with the daemon still running at no CPU, so nothing restarted it. Linux hosts weren't affected.
- **Upgrading a daemon that is just starting no longer stops it.** An upgrade request that arrived as the daemon started could end it and report a timeout. It now waits until the daemon can take the request, and a daemon that exits during an upgrade says so at once.

## Also in it

- **Tab completion is faster to start from an internal disk.** With the model on this Mac's own disk, the model server loads in about 1.3 s, and a typical completion answers in about 340 ms.

## Installing

These builds aren't signed yet, so macOS and Windows will warn you the first time.

**Mac (Apple silicon).** Download `Polaris-0.1.0-alpha.5-arm64.dmg` and drag Polaris to Applications, then open it. macOS will refuse the first time. Open System Settings → Privacy & Security, scroll to the message about Polaris, click **Open Anyway** and confirm. On macOS 14 and earlier, right-click Polaris in Applications and choose **Open** instead.

**Windows.** Download `Polaris-0.1.0-alpha.5-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

You'll also need at least one agent, like Claude Code or Codex, installed wherever you want agents to run.

## Known limitations

- **No automatic updates between alphas.** Prereleases aren't on polaris.lux.dev or its update feed, so install the next alpha from this page by hand. The unsigned Mac app can't update itself at all, so checking for updates on a Mac says "Couldn't check for updates".
- **Unsigned.** Gatekeeper and SmartScreen warnings are expected until signing is set up.
- **Mac app is Apple silicon only.** Linux machines (x64 and arm64) work as hosts, not as a desktop app.
- **Windows is experimental.** No local host, and CI only smoke-tests the x64 installer. If signing in to GitHub fails on Windows, tell us which page refused.
- **Edit predictions are tuned for TypeScript.** Other languages get suggestions without the language-server check.
- **A Raspberry Pi 4 doesn't serve completion.** Point it at a model server on a larger machine.
