Your phone joins Polaris: link an iPhone to your hosts through the Polaris Relay, get pushed when an agent needs you, and answer from the lock screen. Plus plan mode, word wrap and a security update to the daemon's runtime.

## What's new

### Linked devices and the Polaris Relay

- **Link a phone.** Settings → Devices shows a QR code; scan it with the Polaris iPhone app (in TestFlight for now) to link the phone to every host this Mac knows. The list shows each linked device, and **Unlink** cuts it off on every host.
- **The Polaris Relay.** A host can be reached through the relay as well as over Tailscale: choose the route per host in Settings → Hosts. Phone and host both dial out to the relay, and everything between them is end-to-end encrypted; the relay forwards bytes it can't read. Ours runs at `wss://relay.polaris.lux.dev/v1`, and you can run your own (`apps/relay`).
- **Push.** When an agent session needs you or a turn finishes, the host wakes your phone. The notification is sealed to the phone, so neither the relay nor the push service can read it, and you can approve or reply from the lock screen.
- **Constellation notifications.** A constellation that needs you notifies on its own. Settings → Sessions turns constellation notifications off on this Mac; the phone has its own switch.
- **Copying a link** marks it concealed and clears it from the clipboard after a minute.

### Agent sessions

- **Plan mode.** Hosts that support it offer **Plan** in the permission picker: the agent plans before it edits. Older Clients see such sessions as Supervised.

### Desktop

- **Word wrap.** View → Word wrap (Alt+Z, or the command palette) wraps long lines in the changes rail, Review and the Editor. Polaris remembers it with your appearance settings.
- **Constellation stats as charts.** A constellation's Stats popover now shows cost or tokens, the costliest tasks, time spent by workers, first claims and update turns as charts.

### Extensions (experimental)

- **Raycast pairs.** In 0.3.2, pasting a pairing string failed with "Schema validation failed". Download `polaris-raycast-0.4.0.zip`, unzip it, and in its folder run `npm install` then `npm run dev`. Before each release, the extension is now built the way you install it and paired with a real host.

### Security

- **Bun 1.4.4.** The daemon now embeds Bun 1.4.4, which fixes an out-of-bounds write in its Brotli decoder (CVE-2026-111497), an HTTP/3 memory exhaustion and trust in compromised emSign certificate authorities. Update your hosts.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.4.0-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.3.2 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.4.0 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.4.0-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.4.0 the next time it connects. Linking a phone needs every host on 0.4.0.

## Known limitations
