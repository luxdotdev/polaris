Raycast pairs again, plus word wrap and a new Stats popover for constellations.

## What's new

### Extensions (experimental)

- **Raycast pairs.** In 0.3.2, pasting a pairing string failed with "Schema validation failed". Download `polaris-raycast-0.3.3.zip`, unzip it, and in its folder run `npm install` then `npm run dev`. Before each release, the extension is now built the way you install it and paired with a real host.

### Desktop

- **Word wrap.** View → Word wrap (Alt+Z, or the command palette) wraps long lines in the changes rail, Review and the Editor. Polaris remembers it with your appearance settings.
- **Constellation stats as charts.** A constellation's Stats popover now shows cost or tokens, the costliest tasks, time spent by workers, first claims and update turns as charts.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.3.3-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.3.2 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.3.3 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.3.3-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** The daemon is unchanged apart from its version. With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.3.3 the next time it connects.

## Known limitations

0.3.0's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.3.0) still apply.
