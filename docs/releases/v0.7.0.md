Agent sessions get a Browser. Open a Host address like `localhost:3000` or a Portless `app.localhost` from the Mac, even when the session runs on a remote host, and the session's agents can drive the same tabs. Agents can also answer with Visualizations: interactive charts and diagrams drawn right in the conversation, on the Mac and the iPhone. When an agent needs a secret, it now asks for it without the value ever reaching the event log.

## What's new

### The Browser

- **A Browser in Output** for every agent session, after Changes. Each session keeps its own tabs; logins and cookies are shared across the workspace.
- **Host addresses.** `localhost`, any `*.localhost` name (Portless apps included) and loopback IPs always mean the session's host, never your Mac, so a dev server on a remote host opens as if it were local, hot reload included. The URL bar shows a **Host address** badge in place of the padlock. Every other URL loads from your Mac's own network.
- **Agents drive it.** Claude Code and Codex sessions get browser tools (agent-browser): they can open tabs, read a page, click, type and take screenshots, in the tabs you see. A tab an agent is using says so while its turn runs. Browser tools follow the session's permission mode.
- **Pick an element.** Pick, then click anything on the page: its selector, an HTML excerpt and a screenshot are attached to your next message.
- **No Mac, no Browser.** An agent that reaches for the Browser while no Mac is connected is told "No Desktop App is connected to show this Browser."

### Visualizations

- **Agents can draw.** The new visualize tool lets an agent answer with an interactive chart, table or diagram in the conversation, built on the Polaris look with Chart.js and D3 included.
- **Sealed off.** A Visualization runs in a sandboxed frame that can't reach the network, so nothing it shows leaves your machine. Links open only when you click them.
- **On the iPhone too,** inline in the thread and expanded into a full sheet.
- Settings → Sessions → **Visuals** turns them off.

### Secret Requests

- **An agent asks, you answer.** When an agent needs an API key or a password, it shows a Secret Request card. What you type goes straight to the host, is redacted from every log and output, and never enters the event log or the transcript.
- On the iPhone, answer from the thread's masked card.

### Desktop

- **Settings, redrawn.** Every Settings page is on the new Settings kit, matching the Moonlit and Midnight themes, with removals confirmed in place.
- **Hosts.** A hosts list and a page for each host with live CPU and memory, its harnesses, remote access, and **Restart daemon**.
- **The sidebar** sorts sessions by Active or Newest.
- **Mouse back and forward** move through sessions, Review and editor places, like pages.
- **Commands** are coloured as shell syntax, in the row and the hover card.
- **The completion card** spans the tab and scrolls with the constellation's tasks; a subagent's report stays folded until you open its card.
- **One session in a hundred** gets a rare celestial.

### The iPhone app (TestFlight)

These are in build 11, version 0.7.0.

- **Visualizations** and **Secret Requests**, as above.
- **A session opens its thread,** with Review a button in the session's header.
- **Change a session's permission mode, model, effort and fast mode** from the iPhone; the host used to refuse it.
- **Swiping back** shows the screen beneath instead of black.
- **The Live Activity** draws the rare celestial too, and its widget reads the push key reliably.

### Your hosts

- **agent-browser** is installed on each host for the Browser's agent tools, Linux on ARM included.
- **Linked devices report presence,** so the reach map in Settings is live instead of a five-minute guess.

## Installing

**Mac (Apple silicon).** Download `Polaris-0.7.0-arm64.dmg` and drag Polaris to Applications, then open it.

- **On 0.6.0 or earlier,** Polaris updates itself. Choose **Restart to update** when it says 0.7.0 is ready.

**Windows.** The Windows build still isn't signed, so SmartScreen will warn you the first time. Download `Polaris-0.7.0-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

- **On 0.2.0 or later,** Polaris updates itself.

**Your hosts.** With **Keep daemons up to date** on (Settings → Hosts), each host moves to 0.7.0 the next time it connects. The Browser, Visualizations and Secret Requests need the host on 0.7.0.

## Known limitations

- The Browser is in the desktop app only; the iPhone doesn't have it yet.
- Agent browser tools are for Claude Code and Codex sessions.
- A Codex thread can keep its agent-browser process after its session closes.
- The iPhone app is in TestFlight, by invitation.
- 0.3.0's [known limitations](https://github.com/luxdotdev/polaris/releases/tag/v0.3.0) still apply.
