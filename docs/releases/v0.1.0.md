The first Polaris release. It has everything from the six alphas, and from now on Polaris updates itself.

## What's new since alpha.6

- **Automatic updates.** Polaris checks polaris.lux.dev once at launch and every six hours, downloads a new version in the background, and installs it the next time you quit or choose **Restart to update**. Turn it off with **Check for updates automatically** in Settings → About, or check by hand with **Check for updates…** in the Polaris menu.
- **Downloads from polaris.lux.dev.** The site's download buttons now point at this release, not at the alphas on GitHub.

Nothing else in the app changed since alpha.6. For what's in it, see the notes for [alpha.1](https://github.com/luxdotdev/polaris/releases/tag/v0.1.0-alpha.1) through [alpha.6](https://github.com/luxdotdev/polaris/releases/tag/v0.1.0-alpha.6).

## Installing

**Mac (Apple silicon).** Download `Polaris-0.1.0-arm64.dmg` and drag Polaris to Applications, then open it. The app is signed and notarized, so macOS opens it without a warning.

- **On alpha.6,** Polaris updates itself to this release. Choose **Restart to update** when it says 0.1.0 is ready.
- **On an earlier alpha,** the app wasn't signed and can't update itself. Replace it in Applications with this one.

**Windows.** The Windows build isn't signed yet, so SmartScreen will warn you the first time. Download `Polaris-0.1.0-x64-win-Setup.exe` (or the `arm64` one for ARM PCs) and run it. When SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.

You'll also need at least one agent, like Claude Code or Codex, installed wherever you want agents to run.

## Known limitations

- **Windows is experimental.** It's unsigned, has no local host, and CI only smoke-tests the x64 installer. Automatic updates on Windows are new: if yours doesn't update, install the next release by hand.
- **Mac app is Apple silicon only.** Linux machines (x64 and arm64) work as hosts, not as a desktop app.
- **A host's own downloads don't use a corporate proxy's certificate yet.** Language servers and the edit prediction model download on the host, which doesn't yet trust a certificate a tool like Zscaler installs.
- **Edit predictions are tuned for TypeScript.** Other languages get suggestions without the language-server check.
- **A Raspberry Pi 4 doesn't serve completion.** Point it at a model server on a larger machine.
