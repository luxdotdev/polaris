# Language tooling UI references (Mobbin, 2026-10-06)

Inputs to the v2 design pass (spec `docs/specs/editor-language-tooling-v2.md` §6).
Mobbin has no VS Code, Zed or JetBrains desktop screens; IDE behaviour noted
without a link is from general knowledge.

## Status pill and popover
- Klaviyo usage popover ([16a19718](https://mobbin.com/screens/16a19718-2429-4873-b583-0d473e84ce94)): the fix button sits in the header row.
- Twingate connector status ([63275f9d](https://mobbin.com/screens/63275f9d-787b-482d-b12b-e233f3370988)): fact rows with dot badges, so "ready" can be checked.
- Google Meet troubleshooting ([2c84d1b5](https://mobbin.com/screens/2c84d1b5-fcb2-482e-97cd-1b2c465e5a8c)): Prerequisites as actionable rows.
- Zed: a server menu ending in Restart and View log. No toasts for these states.

## Trust popup
- Cursor permission card ([a773fc91](https://mobbin.com/screens/a773fc91-0d05-4ca2-84d4-d7194628b67d)): one sentence, two buttons.
- Replit permission dialog ([69684dcf](https://mobbin.com/screens/69684dcf-c113-43cd-8d6f-cbcebd1d5ae4)): anchored to the surface, not centred on the window.
- Featurebase ([92e1b1f4](https://mobbin.com/screens/92e1b1f4-18a9-4933-ad64-30d1c77bfe42)): a line saying it can be undone lowers the stakes.
- Avoid: Square's persistent warning banner ([0c18f6a3](https://mobbin.com/screens/0c18f6a3-c97a-484f-b403-99fdfaf41676)).

## Command Palette
- Supabase ([9b4725f5](https://mobbin.com/screens/9b4725f5-e038-4fc7-98ad-64a59f74b4d7)): groups, right-aligned keycaps, "…" on multi-step commands.
- Vapi ([593d7acd](https://mobbin.com/screens/593d7acd-2e16-4365-bcd6-02ce52f48f3b)): Recent first on an empty query; result count in the footer.
- Devin ([274435b9](https://mobbin.com/screens/274435b9-f420-4a7c-ab68-82514c1419f9)): faint argument hints.
- Juicebox ([2af813bf](https://mobbin.com/screens/2af813bf-0129-45d1-81ed-069edee76e16)): footer key legend; Tab jumps groups.
- Easter eggs: search-only, never in the default list.
