# C1 Client language access and Desktop IPC

Base: `f4534879f2b79b218d334ec2e41c1652e141de2c` (accepted G1).

## Delivered boundary

`packages/client/src/languages/index.ts` provides `LanguageAccess` and closed
request/feed tables derived from accepted RPC schemas. Every payload, response
and stream item is decoded. Both broad language and method-specific capabilities
are required; preview media retains its independent capability. Foreign Host,
Client and unacquired context identities fail closed. Installation consults the
Host catalog and rejects missing/evaluation entries. Host preflight, artifact
verification, trust and activation still belong to the Host services and A1.

`LanguageAccess` owns no socket/parser/SSH connection. Its injected transport
uses the existing connection's authenticated identity, capabilities, loss signal,
request dispatch, stream dispatch and bounded Blob consumer. Calls have a 30 s
ceiling and a 128-call admission bound; connection loss/disposal cancels pending calls and feeds even if a fake
transport ignores abort. Disposal clears local ownership and makes a bounded,
best-effort release of live interests. Release has no disk mutation retry.

`LanguageDocuments` maintains a bounded serial synchronization queue, acquires
Daemon-issued context/generation snapshots, reads current Client buffer snapshots
on reconnect, and sends full opens before feature requests. Requests require
acknowledged exact versions and queue cuts. Typing/invalidation, disconnect,
settings/disk invalidation, queued old-generation work and mismatched results prevent obsolete results from
being applied. The caller must notify `invalidate()` immediately on local buffer,
disk or Settings changes and use `sync()` for ordered notifications. Unknown
resource operation outcomes must be queried; these adapters do not replay edits.

`apps/desktop/src/main/languages/` supplies the neutral `LanguageApi` adapter,
main-owned `LanguagePreferences`, and media bridge. Settings records use revision
compare-and-set and precedence App < Language < Host < Workspace <
Workspace-language, with field origins and effective paths preserved. Arrays/maps
are whole-field overrides. Other app preferences survive writes. Defaults keep
format-on-save enabled. Preview consent is independently keyed by Host/Workspace.
App and per-language preferences are available before any Host is configured.
Private environment values stay in Settings/launch configuration; boundary errors
expose only fixed reason text and never parser/transport messages or input values.

`main/settings.ts` adds bounded language records/policies to the existing app
Settings schema and validates whole-file writes before creating a private sibling
file and renaming it atomically. Sibling cleanup runs after failures. Language
preferences do not persist installation/progress/readiness facts.

The bridge requires registered main Host/Workspace/checkout authority and checks
foreign Host IDs in contexts, scopes and policies. Main's injected language/
association resolver supplies effective persisted settings for discovery,
acquisition and configuration; renderer-supplied effective settings are replaced.
No resolver means those operations fail closed. Install/status feeds remain
Host-derived and are decoded rather than fabricated from preferences.

## Preview media

Relative resources go through the independent, authenticated Host media RPC.
Main resolves contained document-relative parent segments and rejects checkout escapes/absolute resources, asks for policy-bounded bytes,
consumes the existing connection's Blob stream with a byte ceiling and abort
signal, and checks the declared length/MIME against raster magic. Active SVG/HTML
is rejected. Canonical remote path/symlink containment is a required G2 Daemon
handler responsibility; main cannot authorize a remote filesystem by local reads.

External media is fetched only in main after remembered consent. The concrete
Node HTTP adapter sends no cookies, authorization or credentials, validates every
redirect, resolves IPv4 destinations, rejects private/reserved/loopback/metadata
addresses and pins the socket to the validated address while retaining hostname
TLS verification. HTTPS downgrade is refused. Limits: four redirects, 15 seconds,
10 MiB and any smaller per-Workspace/request ceiling. Main admits at most four concurrent media operations. IPv6-only image destinations
are deliberately unavailable. Consent is rechecked before returning bytes.
Renderer receives only validated raster base64/bytes and owns object URL cleanup.
No renderer file/network authority, project dependencies or accounts were added.

## G2 integration recipe and ownership

1. Construct the combined RPC group/client on the existing authenticated Wire
   with one request/response routing owner. Extend stream-tag/ping accounting;
   preserve Agent Session resume. Do not cast `DaemonClient`, create another
   parser/client on the Wire or open another socket/SSH connection.
2. For each negotiated connection create one `LanguageAccess(transport)`.
   `transport.invoke` dispatches its closed typed method on that combined client;
   `watch` adapts a scoped Host stream to an abortable AsyncIterable. `takeBlob`
   must consume incrementally and stop before retaining more than `maxBytes`.
   The transport `signal` ends with that exact connection. Disposal ends the
   access without changing Connection State or aborting unrelated Agent APIs.
3. Provide stable main `LanguageHost` objects from `lookup(hostKey)`, including
   authenticated `hostId`, optional access, canonical registered Workspace/
   checkout authorization and a main-owned language/association resolver.
   Replace the object on connection replacement. Older peers keep access null.
   Build `LanguagePreferences(readCurrentSettings, commitValidatedSettings)`;
   update in-memory app Settings only after its atomic write succeeds.
4. Construct `createLanguageBridge(options)` once for main's lifetime, and opt in
   to `registerLanguageIpc(ipcMain, bridge, trustedAppOrigin)`. Channels are the
   separate exported `LANGUAGE_CHANNELS`; existing IPC APIs remain unchanged.
   Wire the optional preload `PolarisApi.languages` request/subscription methods
   to those channels. Registration bounds per-window feeds and cleans them on
   navigation/destruction. Dispose both registration and bridge at shutdown.
5. For each Editor context construct `LanguageDocuments(acquireInput,
   currentFullSnapshots)`. Await reconnect restoration; use its ordered sync and
   fenced request methods. On loss call disconnect and on replacement use the
   newly authenticated access. Main must recompute effective Settings at actual
   reconnect acquisition; Settings changes invalidate and recreate/reconfigure
   contexts. The generic neutral UI bridge already does this for acquisition.
6. Register canonical contained `languages.preview.media` in G2 and advertise
   capabilities only after its complete handler path passes vertical tests.
   Resolve files/links on the actual Host checkout, including symlinks. M1/M2 own
   renderer preview and object URLs. G2 owns combined existing-connection wire,
   actual preload/main composition, and real fake-Daemon vertical tests.

These seams are implemented and tested through injection. They do not constitute
production connection wiring, installation approval, actual Electron/remote
verification, resource-operation durability or finished M3.1 acceptance.
