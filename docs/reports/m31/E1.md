## Design decision and ownership

The existing CodeMirror view and Desktop draft remain the sole buffer authority.
One retained language interest follows each buffer, including hidden source tabs
and Markdown preview. Provider/project queues are shared across those interests;
closing a view releases only its interest, with final close/release after ordered
work. M2's source/rendered view identities and immutable post-await close fences
remain unchanged. F2 retains all save reasons, disk-write ownership, formatting
registration identities and unformatted fallback feedback. AI ghost text remains
owned by the existing inline adapter.

Language tools use quiet caption controls, safe plain text, existing Polaris
surfaces, and keyboard focus/Escape return to the source view. Manual language
selection changes the open buffer's grammar/document language; persistent
associations remain Settings-owned. Loading, unavailable, capability gaps and
empty results have distinct facts. Actual theme/density/accessibility proof is
pending its renderer slot, rather than inferred from JSX.

## Construction seams

`EditorLanguageCoordinator` implements `EditorLanguagePort`; runtime buffers
mount it once, call `edited` for every actual document revision, call `saved`
only for the exact successfully written revision, and dispose before destroying
or rekeying the view. Grammar loads recheck buffer identity and selected language
before dispatch, so late auto detection cannot overwrite a manual selection.

`LanguageIdentityLookup` is injected, returning independently authenticated
`{hostId, clientId, connectionEpoch}` or null. Acquisitions require the actual
connected Host identity/epoch, registered checkout and coarse negotiated language
capability. Null/old/unwired access stays unavailable. No context echo is used as
identity evidence. Main/preload registration and the checked identity accessor
remain G2-owned, with A0's existing-session transport handoff pending.

`refreshLanguageSettings(hostKey, workspaceId)` is a light Editor API seam. U1
invokes it only after a confirmed matching scope/revision/patch acknowledgment
or trust authority change. It cancels prior configuration/context interests and
recomputes effective Settings; form edits and failed requests do not bind it.

The injected `PrepareLanguageEdit` port follows Lead2958's shape, retaining the
original typed request/result, originating live provider, exact acknowledged
unsaved document and AbortSignal. G2 owns proposal identity, expiry, fence and
canonical disk/text/resource snapshots. Renderer rechecks provider/document and
port lifetime after preparation, routes resource proposals before legacy schema
decoding and rejects resource edits without format2. It creates no authority
fields. R1 owns durable preview/apply/undo. An absent preparer/acceptance binding
shows unavailable and performs no edits or command fallback.

required checks. `lsp/bindings.ts` publishes registration-fenced identity and
proposal consumers; `lsp/preparation.ts` publishes the authoritative preparation
port and union; `api.ts` publishes Settings refresh. The coordinator's synchronous
identity lookup consumes a current independent identity cache; Main's asynchronous
