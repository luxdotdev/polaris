## Containment and bounds

- Decode the accepted payload; compare full checkout identity and canonical path
  to the independent registry using accepted D1 helpers. Resolve the canonical
  existing regular document first, then media relative to its canonical directory.
  Contained parent navigation and contained symlinks are supported. Reject URLs,
  absolute media paths, backslashes, traversal and outside document/media symlinks.
- Canonical paths are opened from `/` using descriptor-relative libc `openat`.
  Every component uses `O_NOFOLLOW`; directory components use `O_DIRECTORY`,
  and all descendants use nonblocking, close-on-exec descriptors. A renamed
  ancestor cannot redirect the next lookup through an attacker symlink.
  Retain the checkout-root and final file descriptors; release traversed parents.
  A walk is capped at 128 components. At steady state two walks retain four
  descriptors; temporary traversal adds at most one per walk.
- Compare root/document/media inode identities and regular-file versions before
  reading; recheck original lexical/canonical paths and descriptors after reading.
  Hold descriptors through delivery. Reauthorize after async filesystem work,
  then reauthorize again before delivery. After the final authorization completes,
  synchronously verify its full registration and original paths/versions before
  calling the request's BlobChannel. There is no filesystem await between that
  last authorization return and the offer.
- Four admitted requests maximum, including interruption cleanup and Blob offer;
  extra demand returns typed queue-full. Read 64 KiB chunks into at most the
  observed file size plus one byte, capped at caller maxBytes plus one. The wire
  schema limits maxBytes to 10 MiB. Oversize, growth, mutation and nonregular
  files fail before offer. The shared Wire owns bytes after successful offer;
  H1's bound does not certify its aggregate retained-blob or decoded-image budget.
- MIME comes only from raster magic: PNG, JPEG, GIF, WebP and bounded AVIF ftyp
  brands. A raster extension cannot authorize SVG/HTML or arbitrary data.
  This is container recognition, not a complete image decoder or pixel budget;
  the accepted Client validates/decode-handles its raster result.
- Effect Scope holds admission until pending async work settles and descriptors
  close, even on interruption. Abort is checked before/after reads and waits;
  no late Blob offer follows cancellation. Generic filesystem/native/schema
  faults become typed invalid-input without private path/error disclosure.
  Native loading is lazy, uses existing platform conventions, and installs nothing.

macOS native behavior is exercised on the actual temporary filesystem. Linux

Attempt. Other platforms fail closed. Compiled-binary embedding/runtime and
