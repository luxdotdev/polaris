## Behavior and construction

Every real save path uses one per-buffer `SaveCoordinator`: manual `saveFile`,
the actual autosave timer, Save All, Vim handlers, close's Save answer and the
native `editor-save-all` quit callback. Callers await the same in-flight Promise.
Default format-on-save is on; effective App, language, Host, Workspace and
Workspace-language Settings are merged in that order. Explicit None and disabled
Settings skip execution. A selected formatter without a binding fails explicitly.

Preflight covers Settings and formatting with a three-second deadline. Typing,
reload, disk changes, rename and release abort the request. Results must still
match the same buffer, file identity, monotonically increasing document revision,
disk-version reference, writable status and absence of conflict/deletion before
applying. Formatted changes use the existing bounded diff and CodeMirror's mapped
selection/history. Existing line endings stay authoritative. The actual disk
write uses the current text and existing expected-version checks. A write that
leaves newer dirty edits returns false, so close/quit cannot discard them.
Released/replaced views and moved targets cannot adopt a late write result.

Selected unavailable, failed or timed-out formatting still saves current text and
shows the existing Starlight failure toast, saying text is saving without
formatting. Disk failure stays a separate failure/banner; no success toast is
invented. Repeated identical autosave formatting errors coalesce per buffer;
explicit saves still explain their failure. No idle timer/polling/server startup
was added: the deadline exists only while a save request is pending.

E1 binds `bindFormatter(file, { settings, format })` in `formatting/bridge.ts` and
removes the binding when its context is replaced/released. `settings` supplies
the effective flag and selected formatter, including manual language overrides.
`format` receives `{ file, text, version, diskVersion, reason }`, the selected
formatter and an AbortSignal, and returns formatted text. E1 owns negotiated
capabilities, current ordered document ack, project configuration/trust, request
IDs and fences; it must sync this exact unsaved snapshot, call
`LanguageFeatures.format`, reject Failed outcomes and validate the exact context/
document response before converting edits. `formattedText` converts negotiated
UTF-8/16/32 positions, preserves untouched CRLF and rejects out-of-range,
Unicode-splitting, reversed and overlapping ranges. Old/disconnected/missing
bindings do not pretend to format. Replacement bindings cannot service an older
preflight's AbortSignal. Each registration has its own record, including when the
same formatter port object is registered again. Both response admission and the
disposer compare that registration identity. This is local binding ownership;
E1's context generation remains authoritative. A late response after replacement
or cancellation is rejected, and an old disposer cannot remove a newer same-port
registration. Internal disk invalidation discards formatting without a redundant
failure toast while the disk read/version check completes.
