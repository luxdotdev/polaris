The Main helper `loadLanguageCredential(explicitPrivateDirectory)` creates a
256-bit random bearer proof, encoded as exactly 64 lowercase hex digits.
The private directory must be owned by the current Unix user with mode 0700;
the record must be a regular, non-symlink, single-link, current-user file with
mode 0600 and exact valid length. Unsafe/corrupt records fail with a fixed
error; they are never rotated automatically. Creation writes and fsyncs an
exclusive sibling, links the final name without replacement, removes the
sibling and fsyncs the directory. A post-publication fsync failure preserves
that final ownership record. Callers must treat failure as unavailable and
retry durable validation rather than inventing another identity.

This helper uses Unix UID/mode/O_NOFOLLOW semantics; Windows ACL persistence
is not established by these tests. The explicit parent directory is trusted
Main configuration. The bearer assumes the existing private OS/SSH transport
and trusted Host endpoint: it adds no TLS or SSH host authentication. A user
or process able to read the Main private directory or compromise the Host can
impersonate this Client; public IDs are not credentials. A configured expected
HostId prevents endpoint replacement; once authenticated, reconnect must retain
that HostId. Proof bytes remain in Main memory/private persistence and the
authorized outbound hello only. They do not enter renderer APIs, connection
status, public identity, fixed errors or the public runtime trace.

## Typed handoff

- `HostConnectionOptions.clientIdentity?: { proof: Redacted<string>, expectedHostId?: HostId }`:
  injected Main-owned credential, never renderer-supplied identity.
  `HostDirectoryInput.clientIdentity` forwards this input; actual Main loading
  and registration remain Lead-owned.
- Existing hello adds optional redacted `languageProof` and optional public
  `{hostId,clientId}` reply. Public ID is SHA256 of the versioned tuple
  `polaris-language-client-v1`, actual HostId and proof, prefixed `language-`.
  Both ends derive it independently. Malformed proof validation uses a fixed
  safe error, not a schema failure containing its raw value.
- Daemon `bindLanguageIdentity(actualServerClient,hostId,proof?)` binds the first
  hello, including absence. Repeated identical hello is allowed; a changed,
  malformed or foreign-Host hello permanently revokes that object's authority.
  `languageIdentityFor(actualServerClient,hostId)` reads its immutable public
  binding. `revokeLanguageIdentity(actualServerClient)` invalidates it forever.
- **G2 must check independently live connection membership and actual Host,
  associate exact ServerClient objects with the current wire, and invoke revoke
  at connection closure before/with removal.** Retained annotations or numeric
  client IDs cannot replace this check. The getter alone cannot discover that
  an outside-Area server connection finalizer has run.
- `languageSessionAuthority(actualLiveSession)` returns the private-minted
  immutable `{identity,signal,epoch,capabilities}` authority or null. Public
  fields and copied/fabricated sessions cannot mint authority. The scoped
  signal aborts on disconnect/replacement; reconnect has a fresh session/epoch.
  Existing Connection State and Agent resume transitions are unchanged.
- `languageTransportFor(session,currentSessionLookup?)` constructs the accepted
  C1 `LanguageTransport` on that existing typed combined DaemonClient. No second
  client, stream parser, socket, timer or polling. Closed method/feed tables
  validate accepted schemas, capability gaps and Host/Client coordinates before
  dispatch, and validate outputs before delivery. Calls and feeds are canceled
  by caller/connection lifetime; ended consumers release existing RPC stream
  scope. Blob reads use existing `session.blobs.takeStream`, reject before
  retaining excess bytes, and cap requests at 10MiB. G2 preserves existing
  stream-tag/ping accounting and Host context/generation authorization.
- Main/E1 should query the current actual HostConnection session, require
  `languageSessionAuthority` plus current connection state/Host and capabilities,
  create one C1 LanguageAccess from `languageTransportFor`, and dispose the old
  access on scoped abort/replacement. Its existing restore path reacquires
  generation contexts and sends current full snapshots before feature requests.
  Epoch is scoped to a HostConnection; replacement must also compare actual
  session identity/signal, never numeric epoch alone.
