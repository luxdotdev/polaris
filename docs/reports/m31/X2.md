## Durability, bounds and race limits

Journals use separate format-2 `tree-<owner-operation hash>` directories under a
canonical private same-device root outside checkout. Prepared staging/receipts,
each forward/reverse intent/result and affected parent directories are fsynced.
Duplicate exact requests query their durable receipt; changed operation reuse
fails. Recovery revision CAS prevents stale undo. Recovery never resumes forward
application: reverse moves require complete exact owned trees and absent reverse
destinations. Intervening source/destination/backup descendants or occupied absences
cause recovery-required, preserve external content and retain backups. Recovery
itself can restart after either reverse crash boundary. Unresolved and terminal
undo data remain; there is no timer, pruning, global scan or idle activity.

Sorted original/translated descendant and ancestor locks share X1's file queue;
a checkout queue serializes tree planners. Final snapshot validation repeats after
all waits. Operation-private directories are excluded from recursive reacquisition.
Lstat checks every ancestor/entry, regular-file O_NOFOLLOW descriptors hash in
bounded chunks with before/after stat identity/mtime/ctime checks, directory
enumeration streams and is stat-checked, and repeated whole scans detect
instability. Root/ancestor replacement and all descendant changes fail guards.
Initial validation phases each bound all roots, including overlapping reads.
Expanded move manifests cap 32768 entries, 256 MiB repeated file sizes and 2 MiB
encoded moves. Full outcome preflight reserves 512-byte messages/max revision
before mutation and caps 1 MiB. Private journals cap 4 MiB UTF-8 JSON; raw receipt
reads check size and use bounded buffers before JSON parsing. The first durable
prepared journal must fit and persist before any checkout move.

Portable path APIs have no filesystem-wide compare-and-rename/openat isolation.
Adversarial changes between final checks and open/enumerate/rename syscalls remain
an explicit OS TOCTOU boundary. Encountered links are rejected without traversal;
detected races block mutation. The tests cover explicit races, not all hostile
syscall interleavings or untested platforms. Disk/fsync failures may leave an earlier
durable receipt; callers must query and must not infer success from in-memory state.
