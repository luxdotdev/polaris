# Scope the file pill's installation feed to its Language Integration

On the Pi, opening Python's pill verified the entire Host catalog, including
private Node, TypeScript and its server, while Python discovery was checking
basedpyright. Those unrelated reads competed inside the two-second preflight
window and prevented Python from starting.

The pill subscribes after discovery, when Starting may download managed tools.
Its Host snapshot requests only its integration's providers, companions, managed
formatter and catalog prerequisites. Bundled TypeScript additionally needs the
private TypeScript package. Language IDs use the editor's existing document IDs,
including TypeScript JSX and JavaScript JSX. An unsupported language does not
open an empty tool list, which would request the whole catalog.

No verification is skipped for requested tools. Settings retains the complete
Host catalog and the existing Host installation authority remains shared.
